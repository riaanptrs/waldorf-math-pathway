# UI and UX refresh — 5 October 2026

The review found horizontal overflow on the mobile homepage, an overly long introduction, a sign-in form ahead of the learning catalogue, and oversized inherited headings in geometry lessons.

The shared design now uses readable system body text, restrained serif headings, a calm sky and green palette, subtle static clouds, visible focus states and reduced-motion support. The homepage introduces two clear starting routes, moves account registration after learning, and places language selection in the header. Search matches localised titles, blocks and IDs without accents; it combines with grade selection and explains empty results. Selecting an activity moves focus to its heading and identifies the current card.

Geometry pages have a sticky language header, a keyboard skip link, section jump links, balanced heading sizes, framed diagrams, comfortable text widths, larger answer controls, and labelled previous/next navigation. All routes retain Portuguese HTML fallback and bilingual rendering. Print excludes decorative controls and includes worked answers.

Validation: all existing content audits passed; the 52-route bilingual browser audit passed including diagrams, feedback, calculators and print; `node scripts/check-ui-browser.cjs` passed at 320, 390, 768 and 1280 pixels with language synchronisation, search and empty state, lesson heading focus, section targets, skip link and no horizontal overflow. This is practical accessibility verification, not a claim of a complete WCAG certification or user-research study.
