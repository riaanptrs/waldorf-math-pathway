# Waldorf Math Pathway

A first repository for a Waldorf-inspired Grade 7 online math practice site.

The goal is to create a child-friendly website similar in spirit to a Waldorf
pathway: gentle lessons, practical arithmetic, story problems, and exercises
children can complete online. The first focus is Grade 7.

## Current First Step

- Static website that opens from `index.html`
- Original Grade 7 sample math exercises
- Gentle answer checking
- Waldorf-inspired visual direction
- Project structure ready for more lessons

## Curriculum Note

The initial exercise examples are original. Yamie York-style ideas or other
published curriculum materials should be adapted only from notes you own, with
permission, or by creating original exercises inspired by the same learning
goals rather than copying protected workbook text.

## Suggested Next Steps

1. Choose the site name and GitHub repository name.
2. Define the first Grade 7 lesson blocks.
3. Add a lesson/exercise data model.
4. Add more practice types: percentages, ratios, signed numbers, geometry,
   business math, and early algebra.
5. Publish the site once the first learning path feels complete.
